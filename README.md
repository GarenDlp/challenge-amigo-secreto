# Proyecto: Amigo Secreto

Este es un proyecto simple de una aplicación web para gestionar una lista de amigos y seleccionar un amigo secreto aleatoriamente. La aplicación permite a los usuarios agregar nombres a una lista, validar las entradas y seleccionar un nombre aleatorio de la lista.

## Funcionalidades

1. Agregar nombres: Las personas pueden escribir el nombre de un amigo en el campo de texto y agregarlo a la lista haciendo clic en el botón "Añadir".
2. Validar entrada: Si el campo de texto está vacío o contiene un número, se muestra una alerta pidiendo un nombre válido.
3. Visualizar la lista: Los nombres ingresados aparecen en una lista debajo del campo de entrada.
4. Sorteo aleatorio: Al hacer clic en el botón "Sortear amigo", se selecciona aleatoriamente un nombre de la lista y se muestra en la página.
5. Límite de entradas: La lista puede contener un máximo de 10 amigos (este límite puede ser modificado ajustando la variable `maxAmigos` en el archivo JavaScript).
